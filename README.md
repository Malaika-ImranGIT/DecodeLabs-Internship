**My DecodeLabs Internship Projects**

**Project 1: To-Do List**
Simple tool designed to let users organize their daily tasks.
**Features:**
1)Allows the user to enter and add new tasks to a running list.
2)Cleans up accidental extra spaces typed by the user.
3)Displays all saved tasks clearly with numbers.
4)Includes an exit option to close the program cleanly.

**Project 2: Expense Tracker**
Script helps users keep track of their spending by automatically calculating expenses in real-time.
**Features:**
1)Runs continuously so the user can enter multiple numbers one after another.
2)Automatically adds new expenses to a live running total.
3)Includes error-proofing so the program won't crash if the user accidentally types letters instead of a number.
4)Closes down safely and shows the absolute final total when the user types 'quit'.

**Project 3: Random Password Generator**
A functional security tool that quickly builds completely random and non-predictable passwords.
**Features:**
1)Asks the user exactly how long they want their password to be.
2)Pools together letters and numbers using standard Python modules.
3)Generates a completely secure string based on the user's requested length.
4)Prevents program crashes by verifying that the user enters a proper number greater than 0.
